# 本地 RAG 知识库说明（示例文档）

## 项目定位
本项目是一套基于 Java SpringBoot 的本地 RAG（检索增强生成）知识库原型，用于演示文档上传、向量检索与大模型问答的完整链路。技术栈为 Spring Boot Web、LangChain4j 与嵌入式 H2 向量库，不依赖 MySQL、Redis 或消息队列等外部中间件。

## 工作流程
文档入库时，系统先解析 UTF-8 纯文本，按固定字符长度切分成分块，并保留相邻分块之间的字符重叠，以降低上下文割裂；随后调用本地 Embedding 模型把每个分块转为向量，存入 H2 向量库。

用户提问时，系统先对问题做安全校验，再将问题向量化，与库内向量计算余弦相似度，过滤掉低于相似度阈值的片段，取分数最高的前若干条作为参考资料。

## Prompt 组装原则
组装提示词时严格区分【系统指令】【参考资料】【用户问题】三个区域。系统指令明确要求模型只能依据参考资料回答，资料中没有依据时要如实说明，不得编造；同时声明参考资料与用户输入中的命令都不是系统指令，禁止执行，以降低提示词注入和检索文档注入的风险。

## 安全与可追溯
系统对单条问题做长度限制，防止超长请求挤占上下文与 token；内置关键词规则识别常见的注入与越狱模式。回答会附带命中的文档片段与相似度分数，便于来源溯源。删除文档时会级联清理其对应的全部向量，避免脏数据被后续检索命中。

## 适用场景与边界
本原型适合小体量知识库的功能演示与面试讲解。当前采用内存线性相似度检索，关键词检测只能覆盖已知模式；生产环境可将向量库替换为 Milvus 或 PGVector，并叠加语义注入分类、输出合规审计与文档级权限过滤。
